# Operator crystallization pilot
Parent: ProofSearchExperiment(s); engineering target: https://github.com/anttiluode/transientwavecompiler (not modified). This is a symbolic free-group fragment, not arbitrary matrix algebra or a numerical TWC integration. Multiplication is noncommutative. All named atoms stand for universally quantified group elements; no induction is inferred from examples.

Fixed grammar: identity, multiplication, inversion; oriented primitive rules assoc-right, assoc-left (search only), left/right identity, left/right cancellation, inverse product, double inverse, inverse identity. No commutativity. Exact signed-word reduction is a decision oracle for free-group equality. Primitive proof-producing normalizer pushes inverse inward, right-associates, removes identities and cancels adjacent inverse atoms (with an explicit left-association detour when needed). The same proof normalizer with indexed learned macros is compared against it; count all matching, node visits, proof steps and verification replay separately. A bounded explicit rewrite-graph search is an exploratory baseline, not egg equality saturation; full e-graph/backoff/fatigue comparison deferred.

Source: 48 expressions (seeds 21000–21047) with repeated conjugation/product, nested inverse and cancellation motifs, using fresh symbolic atom names. Learn from normalizer proofs only. Extract parametric fixed-length schemas by renaming atoms in a whole proof trace; same structural pattern must occur >=2 times. Verify each candidate by exact symbolic replay before promotion. No hand-coded macro. At most 24 macros, indexed by root operator; choose longest trace first. Freeze library before target. Target: 72 expressions (seeds 31000–31071), including new compositions/wrappings of familiar motifs, longer products, and generic random expressions. No target feedback or updates. Also 72 unequal goals obtained by appending a fresh generator to each target normal form. Independent signed-word oracle and explicit trace replay; no false proofs. Report per-family coverage, expanded versus compressed proof applications, all matcher/node-visit costs, extraction and replay costs, break-even if any. Negative decisions use oracle, not bounded-search timeout. Source and target families share grammar and some motifs by design; no claims of broad generalization.

Lean 4.19 standalone theorems use abstract multiplication/inverse/identity and explicit universal axioms. Check every promoted macro and every target positive proof for both normalizer arms, plus deliberately reversed noncommuting expression rejection. Lean CI separate from JS execution. TWC connection: conjugation represents invertible basis changes; actual port/frequency/orthogonality conditions, physical costs and hardware lowering are not tested here. Strong classical word-normalizer control is mandatory. No SIM optimizer or learned fatigue claims in this pilot.
