# Experiment 7e — online sparse Jacobian organs
Frozen before implementation run or new corpus generation. Motivation: 7d full normal equations dominate the hard unpinned n=6 cases. Gurnee et al., arXiv:2607.15495 §2.3 motivates sparse pursuit, not a claim that the solver implements a neural workspace. Their dictionary is overcomplete and nonnegative; our local signed rotation increments are neither necessarily overcomplete nor nonnegative.
96 fresh constructed feasible cases 74000–74095; first 48 alternate cells 3 and 7 (n=6 unpinned, one/two chords), last 48 cycle cells 0,1,2,4,5,6 (eight each). Same mixed-seed coefficient generation, canonicalization, mask, scale, acceptance metric, path verification as 7d. Solver never receives reference matrix. No previous target or source reused as new evidence. No tuning on 740xx. Frozen S1 schedule from 7d used without fitting.
Eight arms: P8 and S1 using 7d dense linear solve and full Gram formation; P8C and S1C use symmetry-aware normal equations (upper triangle mirrored) and Cholesky with same damping. RB, GS, GP, JO all use that same improved kernel, same 5-plane maximum, same assembly/hold/dissolve policy. RB uniformly samples without replacement using separate deterministic RNG, without computing unused full Jacobian; GS ranks |j^T r|/||j||; GP is signed orthogonal pursuit using modified Gram-Schmidt on selected columns and residual deflation, recomputes candidate projected norms/correlations and recruits one column at a time (not the paper's exact nonnegative gradient pursuit); JO picks GS seed then recruits by absolute normalized inner product to seed, tie by normalized gradient then plane index. No full Gram to assemble. For GS/GP/JO reuse assembly columns on first execution step; only active columns evaluated during hold. Same deterministic perturbations, 8 restarts with cumulative 512-rotation quotas, 120 iterations per restart, damping/clipping/acceptance as 7d. Hold for up to 4 LM attempts; dissolve after two consecutive relative loss improvements below 1e-3 (including rejected steps) or at mu>=1, recompute next iteration; reset hold counter on assembly, do not reset damping. Full-space polish whenever current loss <=1e-5; no promise of convergence. No fatigue, constraint release, source Gram or parameter tuning. All rotate within fixed-port internal orthogonal group; same pin reduction as 7d. Baseline P8/S1 use exact frozen core behavior including staging for S1.
Primary budget both 2,000,000 work units and 4096 rotations, secondary 4096 rotations only. Same metered ledger as 7d plus explicit assembly, dot-product, orthogonalization, sqrt/division/selection and schedule counters, no free Gram. Track assembly count, block/full steps, per-component ledger, successes and paired rescued/lost IDs, per cell and hard 48; cap enforced before charged increments. Count same arithmetic operations in shared kernels; bookkeeping is modeled, not wall time. Source development zero new source fitting for online arms; code/design effort not zero, S1 prior source training recorded in 7d. Generation and independent verification separate. P1 all 96 feasible references pass metric and canonicalization; P2 every returned path passes numerical reconstruction/response; P3 every target row respects its cap and online assembly never forms a full Gram; no directional performance prediction. Baseline equivalence P8/S1 audited against original core on 7d diagnostic IDs 73000–73007 before new evaluation; if mismatched document, not retune. No Lean numerical proof or hardware test. Do not select winner using pooled budget after the fact; primary endpoint success under both caps in hard 48, work and paired counts secondary. Full aggregate and rotation-only diagnostic.
