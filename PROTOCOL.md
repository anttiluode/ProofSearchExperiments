# First-pass protocol (before execution)

Parent: https://github.com/anttiluode/ProofSearchExperiment

These are deliberately small CPU pilots, not an unrestricted Lean prover. No parameter tuning on the reported seeds.

1. Multi-hop: 64 positive/64 paired negative cases, eight rules, three independent directed premise graphs per rule, 3–5 edges on paths from the appropriate anchors to shared witnesses. All ports have two reachable witnesses; all pairwise intersections have one; only one positive rule has a triple intersection. Add dead-end forks and cycles. Shuffle identities and balance winner position. Compare blind rule-order BFS, bounded positive linear wave ranking followed by the same BFS proof reconstruction, and exact reachability with stored parents (which can emit proofs without searching again). Count edge visits for each stage, joins and proof edges separately; no pretend equivalence between a floating-point add/multiply and an integer edge visit. Require independent path checking and exhaustive reachability truth. Wave must beat BOTH exact baselines including its own cost to claim a work win. Report negatives, top-one, and fallback. Depth bound 5, decay .7; no hard pruning.
2. Phase: random independent unit complex phase codes, D=64,256; witness universe N=512,2048; 64 cases per setting, eight candidate rules, shuffled balanced winner, port cardinalities 2,4,8,16,32,64, all pair intersections one. Compare exact set intersection and real mean triple product; also negative scores (no threshold chosen after seeing outcomes). Report top-one and score separation, codebook and encoding costs. Gate >=95% top-one at D<=256; do not confuse domain size with active support. Exact verification remains mandatory.
3. Crystallization: 60 tasks over recurring typed path motifs; compare direct primitive proof assembly, append-only scanning library and exact keyed library. Count all probes and primitive/macro applications, retain expanded certificates. Report cold/warm halves and library growth; distinguish exact memoization from learned pruning. This is a reduced motif-stream test, not full recursive Lean lemma discovery.
4. Policy memory: bounded deterministic policy-selection proxy using measured source and target costs, equal target evaluation budget; compare blank, source-winner-only and source notebook arms. Keep every safety check immutable. This tests a small transfer mechanism, NOT Google's AI-driven SIM; a real AI optimizer requires a separate study.

All certificates must have an independently checked exact witness and directed paths. Generate Lean terms for the multi-hop positives, with explicit local hypotheses and rules (no sorry); Lean kernel execution must be reported separately, never implied by generating source. Preserve raw results and reproduction commands. No claim of novel physics or superiority to Lean/Aesop.
