# Experiment 7d — source-trained parameterized solver organs
Frozen before source or target execution. 96 source IDs 72000–72095, 96 target IDs 73000–73095. Eight balanced cells (n=5/6, one/neither pinned ports, one/two chords), 12 cases/cell. Seed mixed deterministically before PRNG to avoid adjacent coefficient streams; integer couplings 1–7, diagonals 12–20; feasible witnesses used only by generator/verifier. Same canonicalization, metric and rotation/response verification as 7c. Prior 610xx/710xx are diagnostic only.
Compare P2/P8, A8 (full planes), V (fixed restricted then released restarts), R (random valid parameterized motif), M (source-selected motif), ShM (different-cell learned motif), S0 (hand port-first blocks), S1 (source-selected schedule), ShS (different-cell schedule), X (M+S1+V). Same deterministic restart stream per arm and 4096 total rotation cap, 120 iterations per restart, damping/clipping as 7c. Source candidate library: per source case, extract up to five data-dependent forbidden-entry Givens pivots by greedy best immediate residual decrease among mask-compatible planes; store plane/row/zero roles, not coefficients or angles. Group by exact mask signature. Select one motif per cell using source-only candidate frequency (ties deterministic); source development charges every evaluated pivot and lookup/count. S1 chooses between three preset active-plane orderings (port-first, internal-first, alternating) by source-only success then mean modeled work in actual analytic solver runs. Not arbitrary program synthesis. R samples same length from valid forbidden-pivot candidates; ShM/ShS use next compatible cell's learned policy with same n and pin count, choosing the other chord family; inapplicable operations skip and charge. All warm starts recalculate angles from current matrix, no target witness access. Warm start only first restart; subsequent starts identical random perturbation scheme. Staged schedules first 3 iterations on a small block then full planes; alternating schedule switches blocks each iteration. V uses unrestricted last four restarts, no relaxation of orthogonal similarity. X combines these mechanisms. No learned online target updates. Source policy and predictions committed before target execution. P1 all 96 target IDs match a trained topology cell; P2 every returned path satisfies independent response/reconstruction checks, regardless of success; no predicted performance advantage. Log literal IDs.
Report rotation-capped results and a second 2,000,000 modeled-work capped run with conservative per-operation ledger checks (stop before a billed operation exceeds cap); compare success and total ledger, including lookup, warm-start and scheduling. Include source development cost; break-even only when success noninferior and mean target savings positive. Ledger retains 7c fields and adds organ bookkeeping; generation/independent verification reported separately, no timing claim. D1 completion, improved linear algebra and TWC hardware excluded from this experiment; no claim of generalization to arbitrary topologies. All arms use the same numerical solver core; P2/P8 are 7c-style reimplementations, not byte-identical replay unless separately audited. No exact Lean floating-point certification.
